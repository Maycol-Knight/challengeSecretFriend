# 🎁 Secret Friend (Amigo Secreto)

A simple web page to draw secret friends. Perfect for parties and celebrations!

## What does this project do?

This application allows you to:

- Add friends' names
- Make a random draw
- See who your secret friend is

## How to use the application?

1. Type a friend's name in the text field
2. Click "Añadir" or press Enter
3. Repeat until you add all friends
4. Click "Sortear amigo" to see the result

## Project files

- `index.html` - The main web page
- `style.css` - The styles and colors
- `app.js` - The draw logic
- `assets/` - The images

## How to open the project?

### Option 1: Direct download

1. Download all files
2. Double-click on `index.html`
3. Done! It opens in your browser

### Option 2: From GitHub

1. Clone or download the repository
   ```bash
   git clone https://github.com/Maycol-Knight/challengeSecretFriend.git
   cd challengeSecretFriend
   ```
2. Open the project folder
3. Double-click on `index.html`
